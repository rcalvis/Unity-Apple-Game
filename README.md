# Unity Apple Game 🍎

A simple Unity-based game where players collect apples, avoid obstacles, and try to achieve the highest score possible. This project was created as a fun self-exploration of Unity game development and includes core gameplay mechanics, player movement, collision detection, scoring systems, and interactive game elements.

## Gameplay

The goal of the game is to collect as many apples as possible while avoiding hazards.

## Game Link

[Apple Game on Unity Play](https://play.unity.com/api/v1/games/game/d6ce2b65-15f6-440a-9758-306073263014/build/latest/frame)

### Features
- Player movement and controls
- Apple collection mechanics
- Score tracking system
- Collision detection
- Simple UI elements
